# Changelog

## 0.1.0 — Initial public research release

- Publish the reviewed finite-specimen core SEM sandbox under MIT.
- Provide stage XYZ, physical zoom, focus/stigmation, continuous/ROI scans and
  native 1024 acquisition with causal timing and exposure-time metadata.
- Preserve separate authenticated GUI/API transports and observable projections.
- Add standalone foreground startup, explicit GPU selection, shared device leases,
  offline specimen preparation and a pure HTTP example operator client.
- Add pinned installation requirements, CPU/display CI, manual GPU/HTTP acceptance,
  source provenance and current human-review instructions.

Known scope: generic uncalibrated ideal-grounded model; damage/charging inactive;
Linux/WSL2 NVIDIA runtime; buffered records; evaluated-agent confinement pending.
